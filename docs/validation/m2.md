# M2 Validation: Python Indexing and BM25 Search

## Automated checks

On Windows with Python 3.12.14, local checks completed with **43 tests passed and one
skipped**, 93% reported coverage, and passing Ruff lint/format checks. The skipped
integration test requires permission to create a symlink; a separate mocked test
exercises link filtering. Coverage excludes execution inside subprocesses, although
their exit codes and returned results are asserted by integration tests.

Tests cover source encodings and exact line ranges, decorators/nested definitions,
bounded chunks, ignore rules, diagnostics, stable IDs, invalid indexes, safe rebuilds,
hand-calculated BM25 scores, and separate-process searches after removing source files.
The existing CI workflow runs the expanded suite on Windows and Linux after push.

## Example rankings and limitations

| Query | Observed behavior |
| --- | --- |
| `cookiejar_from_dict` | Rank 1 is the matching function in `src/requests/cookies.py`, lines 521–539. |
| `HTTPAdapter send timeout` | Rank 1 is `HTTPAdapter.add_headers`; a chunk of `HTTPAdapter.send` appears at rank 3, lines 693–719. Lexical overlap does not guarantee the best evidence ranks first. |
| `prepare_url` | The top results belong to the similarly named test helper, rather than the production URL-preparation method. Multiple chunks can belong to one symbol. |

These are functional smoke examples, not a relevance-labeled benchmark. No retrieval
quality metric or comparison to future strategies is inferred from three queries.
Keep these failure modes visible when designing M3 labels and M4 baselines.

## Reproduce the source and queries

Run from the project root after `uv sync --locked --dev`. Clone only if the destination
does not exist; for an existing clone, verify its commit and clean status first.

```text
git clone --depth 1 --branch v2.32.3 https://github.com/psf/requests.git artifacts/repos/requests
git -C artifacts/repos/requests rev-parse HEAD
git -C artifacts/repos/requests status --short
uv run --locked sacr index artifacts/repos/requests --output artifacts/requests.sqlite --json
uv run --locked sacr search "cookiejar_from_dict" --index artifacts/requests.sqlite --top-k 3 --json
uv run --locked sacr search "HTTPAdapter send timeout" --index artifacts/requests.sqlite --top-k 3 --json
uv run --locked sacr search "prepare_url" --index artifacts/requests.sqlite --top-k 3 --json
```

Add `--overwrite` to the index command for an existing SACR database. Compare the
commit above and source manifest/configuration before comparing results. Git checkout
line-ending conversion can change byte hashes even when decoded source is equivalent;
quality assertions must not depend on a particular absolute checkout path.

Use the automated suite to reproduce fixture-level invariants:

```text
uv run --locked pytest --cov --cov-report=term-missing
uv run --locked ruff check .
uv run --locked ruff format --check .
uv build
```
